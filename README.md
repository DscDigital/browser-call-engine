# browser-call-engine
API-first browser calling engine for CRM, ERP and B2B communication platforms.

## Documentation
The repository stores the current architecture and MVP design in the `docs/` folder.

Key docs:

- `docs/MVP_SCOPE.md` - frozen MVP boundaries and success criteria
- `docs/USER_JOURNEY.md` - telecaller workflow from login through history
- `docs/ROUTES.md` - route map and page responsibilities
- `docs/STATE_MACHINE.md` - authentication, presence, and call lifecycle states
- `docs/UI_UX_ARCHITECTURE.md` - component layout and UX patterns
- `docs/WIREFRAMES.md` - low-fidelity page wireframes in ASCII form
- `docs/COMPONENT_ARCHITECTURE.md` - frozen component tree and state ownership
- `docs/GLOBAL_LAYOUT_ARCHITECTURE.md` - root layout, providers, and persistence rules
